# Сессия: Tags UI + Preset Management
**Дата:** 2025-01-05

## Что сделано

### 1. Tags UI вместо textarea
- Заменён textarea на визуальные теги (chips)
- Каждое слово — отдельный кликабельный тег
- Счётчик скрытых постов рядом с каждым словом
- Поле для быстрого добавления новых слов (Enter или кнопка)

### 2. Разделение на кастомные и предустановленные слова
- **Кастомные** — пользовательские слова (красные теги, можно удалить)
- **Предустановленные** — встроенный список (~90 слов, зелёные теги)
- Пресеты можно свернуть/развернуть (кнопка ▼)
- Состояние свернутости сохраняется в `chrome.storage.local`

### 3. Управление пресетами
- Любой пресет можно отключить (клик ×)
- Отключённые пресеты визуально отличимы (серые, полупрозрачные)
- Отключённый пресет можно восстановить (клик +)
- Счётчик показывает активные/общее количество: `85/90`

### 4. UX улучшения
- Предупреждение о необходимости сохранения (пульсирующее)
- Кнопки зафиксированы внизу popup (всегда видны)
- Добавленное слово попадает в начало списка
- `Ctrl+S` для сохранения

### 5. Вынесение стилей
- Все стили вынесены в `popup.css`

### 6. Вынесение пресетов
- Предустановленные слова вынесены в `presets.js`
- Загружается в `content.js` через `manifest.json`
- Загружается в `popup.js` через `<script>`

## Хранилище chrome.storage.sync

| Ключ | Тип | Описание |
|------|-----|----------|
| `customKeywords` | array[] | Пользовательские слова |
| `disabledPresets` | array[] | Отключённые пресеты |

## Хранилище chrome.storage.local

| Ключ | Тип | Описание |
|------|-----|----------|
| `presetsCollapsed` | boolean | Свернуты ли пресеты |
