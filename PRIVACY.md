# Политика конфиденциальности
**DTF: Без розыгрышей**

Дата вступления в силу: 6 января 2026 г.

---

## 1. Сбор данных

Расширение **НЕ собирает, НЕ хранит и НЕ передаёт** персональные данные пользователей.

Данные расширения ограничены настройками фильтрации:
- Список пользовательских ключевых слов
- Список отключённых предустановленных слов
- Настройки интерфейса (уведомления, свёрнутость секций)

## 2. Локальное хранилище

Расширение использует два типа хранилища Chrome:

| Тип | Назначение | Синхронизация |
|-----|------------|---------------|
| `chrome.storage.local` | Настройки уведомлений, состояние UI | Нет, только локально |
| `chrome.storage.sync` | Ключевые слова для фильтрации | Да, между устройствами одного аккаунта Google |

Данные шифруются при передаче и хранятся на серверах Google только для purposes синхронизации.

## 3. Разрешения

| Разрешение | Зачем нужно |
|------------|-------------|
| `storage` | Для сохранения настроек фильтрации |
| `host_permissions` (dtf.ru) | Для работы content script на сайте DTF.ru |

## 4. Сторонние сервисы

Расширение **НЕ использует**:
- Аналитику (Google Analytics, Яндекс.Метрика и др.)
- Рекламные сети
- Трекеры
- CDN
- Любые внешние API

## 5. Доступ к данным

Данные доступны только:
- Пользователю на его устройствах
- Расширению в рамках его функционала

Разработчик **НЕ имеет доступа** к настройкам пользователей.

## 6. Удаление данных

Для удаления всех данных расширения:
1. Откройте `chrome://extensions/`
2. Найдите «DTF: Без розыгрышей»
3. Нажмите «Удалить»
4. Подтвердите удаление

Или очистите данные сайта:
1. Откройте `chrome://settings/content/all`
2. Найдите dtf.ru
3. Нажмите «Удалить данные»
